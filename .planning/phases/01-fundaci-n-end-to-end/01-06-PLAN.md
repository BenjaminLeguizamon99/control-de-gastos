  <action>
Con `API=<URL de Render>` y `WEB=<URL de Pages>` que dio el usuario (si Render está dormido, el primer curl puede tardar ~1 min: usar `--max-time 120`):
1. `curl -s --max-time 120 "$API/health"` contiene `"status":"ok"`.
2. `curl -s -o /dev/null -w "%{http_code}" "$API/me"` == 401 y con `-H "Authorization: Bearer x.y.z"` == 401.
3. Preflight: `curl -s -i -X OPTIONS "$API/me" -H "Origin: $WEB" -H "Access-Control-Request-Method: GET" -H "Access-Control-Request-Headers: authorization"` incluye `access-control-allow-origin: $WEB`; con `-H "Origin: https://evil.example"` no incluye `access-control-allow-origin`.
4. SPA fallback: `curl -s -o /dev/null -w "%{http_code}" "$WEB/recuperar"` == 200 y el HTML contiene `<div id="root">`.
5. Bundle: descargar los `assets/*.js` referenciados en `$WEB/` y verificar que no contienen `sb_secret_`, `service_role` ni `pooler.supabase.com`, y que sí contienen el host de Render (VITE_API_URL quedó inyectada).
6. Registrar en el SUMMARY cada resultado (sin keys).
Si falla CORS, revisar que `CORS_ORIGINS` en Render sea exactamente `["<WEB>"]` sin barra final y pedir al usuario corregirlo.
