| navegador -> API | access_token como Bearer |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-16 | Information Disclosure | env del frontend | mitigate | Solo VITE_SUPABASE_URL, VITE_SUPABASE_PUBLISHABLE_KEY, VITE_API_URL; grep que prohíbe service_role/sb_secret/DATABASE_URL en src (D-03) |
| T-01-17 | Information Disclosure | supabase-js data API | mitigate | Prohibido `supabase.from(...)`; todo dato pasa por FastAPI (grep de aceptación) |
| T-01-18 | Repudiation/Session | ProtectedLayout logout | mitigate | `signOut({scope:'local'})` + `queryClient.clear()` para no dejar datos cacheados de la sesión |
| T-01-19 | Information Disclosure | tokens en localStorage | accept | Comportamiento estándar de supabase-js en SPA; sin contenido de terceros (sin XSS vectors: no se usa dangerouslySetInnerHTML) |
| T-01-20 | Spoofing | mensajes de error de login | mitigate | Mensaje único "Email o contraseña incorrectos" sin revelar si el email existe |
